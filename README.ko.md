# Claude Export Viewer

[English](README.md) | [Français](README.fr.md) | [Español](README.es.md) | [Deutsch](README.de.md) | [Italiano](README.it.md) | [Português](README.pt.md) | [Nederlands](README.nl.md) | [Polski](README.pl.md) | [Русский](README.ru.md) | [中文](README.zh.md) | [日本語](README.ja.md) | **한국어**

CEV는 Claude.ai 대화 내보내기를 **로컬 라이브러리**로 바꿉니다. 인터넷 없이 브라우저에서 읽는 사이트로, 대화를 검색하고 주석을 달고 재구성하고 내보낼 수 있습니다. 새 내보내기는 이전 것에 더해지므로, 나중에 claude.ai에서 삭제된 것까지 아무것도 사라지지 않습니다.

> 독립 프로젝트이며 Anthropic과 제휴 관계가 없습니다. Claude는 Anthropic의 상표입니다. Linux(Ubuntu 26.04, Python 3.14)에서 설계하고 테스트했습니다. Windows와 macOS에서도 작동할 것이지만 아직 시험해 보지 않았습니다. 12개 언어.

## 설치

1. Python 3와 라이브러리 네 개를 설치합니다.
   - Ubuntu / Debian: `sudo apt install python3-jinja2 python3-mistune python3-pydantic python3-pygments`
   - Windows(Python 3.11 이상): `py -m pip install jinja2 mistune pydantic pygments`
2. `claude-export-viewer.zip`의 압축을 풀고 **Installer CEV**를 두 번 클릭합니다(Linux는 `.sh`, Windows는 `.cmd`, macOS는 `.command`).

프로그램은 `~/claude-export-viewer`에 놓이고 **Claude 라이브러리** 아이콘이 만들어집니다. 업데이트도 새 ZIP으로 같은 방법입니다. 대화는 절대 건드리지 않습니다.

## 첫 가져오기

1. claude.ai에서(웹사이트 또는 데스크톱 앱. 모바일 앱에서는 안 됩니다): **설정 > 개인정보 보호 > 데이터 내보내기**. 이메일이 오면 그 링크(24시간 유효)가 작은 '매니페스트' 파일을 내려받습니다.
2. 아이콘으로 **Claude 라이브러리**를 엽니다. **데이터 관리** 탭에서 **내보내기 가져오기** 틀을 클릭하면, CEV가 내보내기의 링크를 브라우저에서 하나씩 열어 모두 가져오고 대화를 보여 줍니다.

가끔 반복하세요. 새 내보내기가 보관함을 보완합니다.

## 라이브러리: 두 부분

라이브러리는 두 부분으로 되어 있습니다. 모든 대화를 나열하는 **목차**와 각 **대화**의 페이지입니다.

## 목차

![목차의 윗부분](docs/en/sommaire.png)

맨 위에 언어, 그다음 탭 세 개가 있습니다. 한 번에 하나만 열리고, 열린 탭을 클릭하면 닫힙니다.

**개요**: 대화·메시지·토큰 수, 사이트 크기, 주별 활동. **막대를 클릭하면 목록이 그 주로 좁혀집니다.** 백업을 권할 때는 크기 타일의 색이 바뀌고, 이때 클릭하면 **라이브러리 백업** 버튼으로 이동합니다.

![개요](docs/en/vue-ensemble.png)

**데이터 관리**: 가져오기, 그다음 라이브러리 도구. **분류 관리**(이름 바꾸기, 합치기, 삭제), **라이브러리 백업**(날짜가 붙은 ZIP), **모두 내보내기**(CEV 없이 읽을 수 있는 Markdown), **공간 확보**(더 이상 필요 없는 파일), **주석 복구**(CEV는 주석의 최근 5개 상태를 보관합니다), **보관함 확인**(보관된 내보내기로 손상된 대화 복구), **제거**(먼저 모든 것의 사본을 제안합니다).

![데이터 관리](docs/en/gestion.png)

**필터**: 제목과 내용 검색(텍스트, 수식: `\alpha` 또는 `α`), **허용 오타** 수 지정, 분류, 기간, 정렬.

![필터](docs/en/filtres.png)

**목록**: 각 대화의 날짜, 크기, 주석(즐겨찾기, 링크, 메모). 오른쪽 메뉴로 **분류**를 지정합니다. 두 대화를 **연결**하려면 하나를 다른 하나 위로 끌어다 놓습니다.

![대화 목록](docs/en/liste.png)

## 대화

![대화의 윗부분](docs/en/discussion.png)

맨 위: 제목, 그리고 오른쪽에 **보기**(읽기 또는 구조). 그 아래에 처음에는 닫혀 있는 탭이 있습니다. 한 번에 하나만 열리고, 열린 탭을 클릭하면 닫힙니다.

- **말풍선**: **숨기기**로 화면을 가볍게 합니다(AI의 리소스, 메모, 제목, 번호, 다른 버전과 삭제된 부분). **표시**는 각 말풍선을 1, 3, 5줄로 줄이고, **음성**은 소리 내어 읽기에 쓸 목소리를 고릅니다. 선택은 대화가 바뀌어도 유지됩니다.
- **내보내기**: .md, .odt, .docx, .txt, .pdf 파일. 주석과 다른 버전을 포함할지 고를 수 있고, 원하면 ZIP으로 받을 수 있습니다.
- 페이지의 **링크**, **즐겨찾기**, **메모**, **제목**: 클릭하면 그곳으로 이동합니다.

**말풍선**은 claude.ai에서와 같이 표시됩니다. Markdown, '복사' 버튼이 있는 색칠된 코드, 수식, 아티팩트(Claude의 프로그램이 페이지 안에서 오프라인으로 실행됩니다), 첨부 문서 전체.

![말풍선](docs/en/bulles.png)

- 날짜 뒤에는 말풍선의 아이콘: **즐겨찾기**, **메모**, **제목**, 복사, 이 메시지 내보내기, 눈(내 메시지에서: Claude의 답변 보이기/숨기기), **소리 내어 읽기**.
- 이름 앞에는 대화 속 말풍선의 위치: `1 ← 2 → 2.1 3` = 질문 2는 1 다음에 오고, 다른 답변(2.1)이 있으며, 그 뒤에 3이 옵니다. 동그라미를 클릭하면 그곳으로 이동합니다.
- **다른 버전**: 메시지를 수정했거나 답변을 다시 생성한 경우, 다른 버전도 이 틀 안에서 제자리에 그대로 읽을 수 있습니다.
- **강조** 5가지 색: 구절을 선택한 다음 옆에 나타나는 펜(또는 오른쪽 버튼)을 클릭합니다.

아주 긴 대화는 여러 페이지로 나뉘어 표시되며('5부 중 2부'), 질문과 답변이 갈라지는 일은 없습니다. 이때 페이지 내 검색, 구조, 내보내기는 표시된 부분에만 적용됩니다.

**구조**는 대화의 도식을 보여 줍니다. 번호가 붙은 질문, 가지로 나뉜 버전. 클릭하면 한 질문과 그 모든 답변이 나타납니다. 실제 순서는 그대로 둔 채 **논리적 순서를 재구성**할 수 있습니다(질문을 답변 뒤로 끌기, 가지 잘라 내기, 초록색 논리 링크 긋기). 구조 막대의 '순서: 실제 · 논리'로 둘 사이를 전환합니다.

![구조](docs/en/structure.png)

**시리즈**: 한 대화가 다른 대화로 이어질 때는 **링크** 탭을 열고 연결된 대화를 원하는 순서로 끌어다 놓습니다. 그러면 시리즈의 각 페이지 위아래에 '← 이전 · 다음 →'이 표시됩니다.

![시리즈](docs/en/suite.png)

<img src="docs/en/boutons.png" align="right" width="70" alt="오른쪽 버튼">

**오른쪽 버튼**은 두 틀로 나뉩니다. 위: 강조(휠로 색 선택), 목차로 돌아가기, 대화 내 검색, Claude의 답변 모두 숨기기/보이기, 배경 음악, 밝은 테마 또는 어두운 테마, 이전 또는 다음 페이지(‹ ›). 아래: 내 이전 또는 다음 메시지, 대화 전체 소리 내어 읽기, **느린 스크롤**(휠로 속도 조절), 페이지의 맨 위·가운데·맨 아래. 목차에도 같은 버튼이 있으며, 대화에만 해당하는 버튼은 빠집니다.

**소리 내어 읽기**는 오프라인의 자연스러운 음성([Piper](https://github.com/OHF-Voice/piper1-gpl))을 사용하며, 처음 쓸 때 동의를 받아 설치됩니다. 내 목소리 하나, Claude의 목소리 하나, 그리고 각 문단의 언어에 맞는 목소리입니다.

## 데이터

중요한 것은 모두 **`~/claude_site/archive/`**에 있습니다. 대화, 원래의 내보내기, 주석, 설정입니다. claude.ai에서 삭제된 대화도 그곳에 남아 'claude.ai에서 삭제됨'으로 표시됩니다. 백업하려면 **라이브러리 백업**을 쓰거나 이 폴더를 복사하세요. 모두 되돌리려면 빈 라이브러리에 백업을 끌어다 놓습니다.

## 명령줄

모든 기능은 터미널에서도 쓸 수 있습니다(`python3 claude-export-viewer.py`, Windows에서는 `py`). `--help`로 전체 목록을 볼 수 있습니다.

| 명령 | 효과 |
| --- | --- |
| `~/Downloads -o ~/claude_site` | 폴더의 최신 내보내기를 가져옴 |
| `-o ~/claude_site --serve` | 라이브러리를 엶 |
| `--odt "제목"`, `--docx "제목"` | 대화 하나를 내보냄 |
| `--export-all` | 모든 대화를 Markdown으로 |
| `--verify`, `--repair` | 보관함을 확인하고, 복구할 수 있는 것을 복구함 |
| `--uninstall`, `--restore ZIP` | 제거, 백업에서 복원 |

## 추가 구성 요소와 라이선스

CEV는 Judson Neer의 [claude-export-viewer](https://github.com/lordjabez/claude-export-viewer)에서 출발했으며, 그에게 감사드립니다. 그 뒤로 크게 바뀌고 확장되었습니다.

- **Pandoc**(.odt, .docx 내보내기용): `sudo apt install pandoc`(Windows: `winget install --exact --id JohnMacFarlane.Pandoc`, macOS: `brew install pandoc`).
- **Piper**(소리 내어 읽기용): 처음 쓸 때 CEV가 제안합니다(약 200MB, 목소리마다 60MB 추가).

**MIT 라이선스**(파일 `LICENSE`)의 자유 소프트웨어이며, 아무런 보증 없이 제공됩니다. 포함: KaTeX(MIT). 요청 시 별도 설치: Piper(GPL-3). 테스트: `python3 -m pytest tests/`.
