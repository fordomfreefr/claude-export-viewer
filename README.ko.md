# Claude Export Viewer (버전 2026.10.25.1)

[English](README.md) | [Français](README.fr.md) | [Español](README.es.md) | [Deutsch](README.de.md) | [Italiano](README.it.md) | [Português](README.pt.md) | [Nederlands](README.nl.md) | [Polski](README.pl.md) | [Русский](README.ru.md) | [中文](README.zh.md) | [日本語](README.ja.md) | **한국어**

Claude.ai의 대화 기록을 인터넷 연결 없이 어떤 브라우저에서도 열 수 있는 로컬 HTML 사이트로 바꾸고, 대화의 누적 아카이브를 보관합니다. 이후 Claude.ai에서 삭제된 대화도 남습니다.

![스크린샷](docs/apercu.png)

이 프로젝트는 Judson Neer의 [claude-export-viewer](https://github.com/lordjabez/claude-export-viewer)를 바탕으로 크게 수정하고 확장한 것입니다(“라이선스와 감사의 말” 참고).

> 이 프로젝트는 독립 프로젝트이며 Anthropic과 제휴 관계가 없습니다. Claude는 Anthropic의 상표입니다.

> Linux Ubuntu 26.04에서 Python 3.14와 JavaScript로 설계하고 테스트했습니다. Windows에서도 동작할 것입니다. 코드는 Claude(Opus 5.5 모델, 높은 추론 수준)를 사용해 작성했습니다. 이 README는 프랑스어판을 기계 번역한 것입니다.

## Linux Ubuntu / Debian 빠른 시작

1. claude.ai에서 대화 기록을 받습니다: **설정 > 개인정보 보호 > 데이터 내보내기**. 먼저 안내 이메일이 오고, 이어서 “매니페스트” 파일을 다운로드하는 링크가 담긴 두 번째 이메일이 옵니다.

2. 터미널에서 4개의 라이브러리와 Pandoc을 설치합니다:  
`sudo apt install python3-jinja2 python3-mistune python3-pydantic python3-pygments pandoc`

3. 프로그램 `claude-export-viewer.zip`을 `~/다운로드`에 저장합니다.

4. 홈 폴더에 압축을 풀고 실행합니다. 매니페스트를 바탕으로 내보내기 파일이 다운로드되어 가져와지고, 이어서 목차가 열립니다.  
`cd ~/다운로드 && unzip -o claude-export-viewer.zip`  
`rm -rf ~/claude-export-viewer && mv claude-export-viewer ~/`  
`cd ~/claude-export-viewer`  
`python3 claude-export-viewer.py ~/다운로드 -o ~/claude_site`  
(`rm -rf`는 이전 버전의 프로그램만 지웁니다. 대화는 `~/claude_site`에 있습니다.)

5. 한 번만, 바탕 화면에 실행 아이콘을 만듭니다:  
`python3 claude-export-viewer.py -o ~/claude_site --install-icon`

## 기능

- 모든 대화의 **전체 목차**:
  - 제목 검색과 결과 개수 표시;
  - 대화 정렬: 만든 날짜, 마지막 대화 날짜, 제목, 메시지 수;
  - 각 대화 오른쪽의 작은 메뉴에서 고르는 나만의 **분류**로 원하는 대로 필터링.
- **각 대화 페이지**:
  - 현지 날짜와 시각, **claude.ai에서 열기** 링크(아직 남아 있는 경우);
  - 서식이 적용된 Markdown(굵게, 목록, 표)과 강조 표시된 코드(Pygments);
  - 언어 이름과 **복사** 버튼이 있는 코드 상자(정확한 코드를 클립보드에 복사);
  - **LaTeX처럼 표시되는 수식**(KaTeX, 포함, 오프라인): `$…$`, `$$…$$`, `\(…\)`, `\[…\]`. 글을 복사하면 수식의 LaTeX 원본이 복사됩니다. 표시할 수 없는 수식은 원본으로 남고, 이유는 도구 설명에 표시됩니다;
  - 아티팩트 표시(코드, 문서. HTML/SVG는 코드로 표시되며 절대 실행되지 않음);
  - 생각 과정, 도구 호출, 결과는 접을 수 있는 블록에 표시;
  - **여러 버전**: 메시지가 수정되었거나 답변이 다시 생성된 경우, 페이지는 마지막 대화로 이어지는 버전을 따라갑니다. 다른 버전은 대화가 갈라진 위치에 있는 접을 수 있는 “다른 버전” 상자에 들어갑니다;
  - **Markdown, LibreOffice(.odt), Word(.docx)로 내보내기**: 각 대화에 “.md” 버튼이 있습니다. 파일에는 기본 흐름과, 기울임꼴 레이블이 붙은 상자(인용)에 담긴 다른 모든 버전이 갈라진 위치에 들어갑니다(확인란을 해제하면 기본 흐름만). `$…$` 형식의 수식, 코드, 아티팩트, 첨부 파일 이름이 포함됩니다(생각 과정과 도구 결과는 제외). Typora, Obsidian, Zettlr에서 읽을 수 있고 Pandoc으로 변환할 수 있습니다;
  - 브라우저 인쇄 창을 통한 **PDF 내보내기**(수식 포함).
- **누적 아카이브**: 여러 번의 내보내기가 중복 없이 추가되고, 이후 claude.ai에서 삭제된 대화도 보관됩니다.
- 목차에서 고를 수 있는 **12개 언어**(페이지, 콘솔, 내보내기).
- 목차를 열고 클릭 한 번으로 새 내보내기를 가져오는 **바탕 화면 아이콘**(Linux, Windows).
- 시스템 설정에 따른 밝은 테마 또는 어두운 테마.

## 설치

이 폴더를 원하는 곳(디스크, USB 메모리 등)에 압축 해제한 다음, 필요한 4개의 라이브러리를 설치합니다.

**Ubuntu / Debian**: 위의 “빠른 시작”을 참고하세요.

**Windows**(Python 3.11 이상, [python.org](https://www.python.org/downloads/) 또는 Microsoft Store에서 설치)에서는 터미널(PowerShell 또는 명령 프롬프트)에서:

```
py -m pip install jinja2 mistune pydantic pygments
```

Windows에서는 이 문서의 명령에서 `python3`을 `py`로, `~/…` 경로를 Windows 경로(`C:\Users\[사용자]\claude_site`, USB 메모리라면 `E:\claude_site` 등)로 바꾸세요. **Windows 지원은 Python과 Windows의 문서를 바탕으로 작성했지만 아직 Windows 컴퓨터에서 실제로 시험해 보지 않았습니다**. 의견을 환영합니다.

## “Claude 보관함” 아이콘(가장 쉬운 방법)

첫 가져오기 후(아래 참고) 아이콘을 한 번 만듭니다:

```
python3 claude-export-viewer.py -o ~/claude_site --install-icon
```

아이콘은 애플리케이션 메뉴와 바탕 화면에 나타나며(Linux. KDE에서는 실행기를 신뢰할지 한 번 물어볼 수 있습니다), Windows에서는 시작 메뉴와 바탕 화면에 나타납니다(PowerShell이 만든 바로 가기로, `pythonw.exe`를 실행하므로 콘솔 창이 열리지 않습니다. 시험해 보지 않음). 클릭하면 작은 로컬 서버(http://127.0.0.1:8000)가 제공하는 목차가 브라우저에서 열립니다. 이 서버는 마지막 페이지를 닫고 30분이 지나면 저절로 멈춥니다(`--idle`로 이 시간을 바꿀 수 있습니다). 두 번째 클릭은 이미 실행 중인 서버를 다시 사용하지만, 그 서버가 이전 버전의 프로그램으로 시작된 것이면 멈추고 교체하여 새 버전이 확실히 쓰이게 합니다. 아이콘을 만들기 전에 프로그램을 고정된 폴더(예: `~/claude-export-viewer`)에 두세요.

아이콘으로 연 목차는 맨 위의 상자에 설정을 모아 둡니다: **새 매니페스트 가져오기**와 **분류 관리** 버튼, 그 아래에 다운로드 폴더와 **변경** 버튼이 있습니다. 각 버튼은 자기 패널을 열고, 한 번 더 클릭하면(또는 X 표시를 누르면) 닫힙니다. **새 매니페스트 가져오기** 버튼: claude.ai에서 내보내기를 요청하고 데이터가 준비되었다는 이메일의 링크를 클릭한 뒤 누르면, 다운로드 폴더에서 가장 최근의 매니페스트를 가져와 링크를 하나씩 열고(링크는 페이지의 로그에도 클릭할 수 있게 표시됩니다), 내보내기를 가져온 다음 목차를 다시 불러옵니다. 가져오는 중에 로그를 닫아도 중단되지 않으며, 다시 클릭하면 로그가 다시 보입니다.

같은 상자의 **다운로드 폴더** 줄은 매니페스트를 찾는 위치를 보여 줍니다. 브라우저가 파일을 다른 곳에 저장한다면(“파일 저장 위치” 또는 “위치” 설정), **변경**을 클릭하고 그 폴더를 입력하세요. 아카이브에 기억되고 시스템 폴더보다 먼저 검색됩니다. 칸을 비우면 시스템 폴더로 돌아갑니다. 선택한 폴더가 사라지면(USB 메모리를 뺀 경우 등) 시스템 폴더가 사용됩니다.

또한 각 대화에서 .md, .odt, .docx 내보내기를 클릭 한 번으로 할 수 있습니다.

**보안**: 서버는 내 컴퓨터(127.0.0.1)에서만 연결을 받으며 원본 아카이브는 제공하지 않습니다. 가져오기에는 목차 페이지만 읽을 수 있는 “비밀 토큰”이 필요하고, 다른 사이트에서 온 요청은 거부됩니다. 같은 브라우저에서 연 웹 페이지가 이를 실행시킬 수는 없습니다.

## 명령줄

1. claude.ai에서: **설정 > 개인정보 보호 > 데이터 내보내기**.
2. 이메일이 오면 그 안의 링크를 클릭합니다. 브라우저가 작은 “매니페스트” 파일(내보내기 파일과 그 링크의 목록)을 다운로드합니다.
3. 다음을 실행합니다:

```
python3 claude-export-viewer.py ~/다운로드 -o ~/claude_site
```

프로그램은 폴더에서 가장 최근의 매니페스트를 가져와 다음을 합니다:

- claude.ai에 로그인된 브라우저에서 각 링크를 직접 **하나씩** 열고, 각 다운로드가 끝나기를 기다립니다(링크는 한 번 쓰면 더 이상 작동하지 않을 수 있습니다);
- 이미 다운로드한 파일을, 브라우저가 이름을 바꿨더라도(`conversations-000 (1).zip`) 찾아내고, 이전 내보내기의 파일은 무시합니다;
- 파일을 `~/claude_site/archive/exports/<날짜>/`로 옮깁니다;
- 내보내기를 아카이브로 가져오고 목차를 엽니다.

기본적으로 쓸모 있는 파일(대화, 프로젝트, 계정)만 가져옵니다. 옵션:

- `--all`: 내보내기의 7개 파일을 모두 가져오기(전체 백업);
- `--browser brave-browser`: 링크를 열 브라우저 선택;
- `--manual`: 아무것도 열지 않기. 링크가 터미널에 하나씩 표시되고(Ctrl + 클릭으로 열거나, 오른쪽 클릭 > 주소 복사로 원하는 브라우저에 붙여 넣기), 파일이 도착하는 즉시 다음으로 넘어갑니다;
- `--timeout 600`: 각 다운로드를 최대 600초 기다리기(기본 300초, 수동 모드에서는 900초);
- `--no-browser`: 마지막에 목차를 열지 않기;
- `--downloads 폴더`: 브라우저가 다운로드를 저장하는 폴더를 기억하기(목차의 “변경”과 같은 설정). `--downloads ""`는 시스템 폴더로 돌아갑니다. 가져올 파일 없이 이 옵션만 쓰면 설정을 저장하고 끝납니다.

각 옵션에는 프랑스어 이름도 있으며(`--tout`, `--navigateur`, `--manuel`, `--delai`, `--sans-navigateur`, `--telechargements` 등), `--help`로 볼 수 있습니다.

**조건**: 링크를 여는 브라우저에서 claude.ai에 로그인되어 있어야 합니다(내보내기 링크는 로그인된 세션에서만 작동합니다). 자동 모드에서는 각 링크가 터미널에도 표시됩니다. 엉뚱한 브라우저가 열렸다면 올바른 브라우저에서 열면 되고, 프로그램은 그래도 파일을 찾아냅니다. Ctrl + C로 깔끔하게 멈출 수 있고, 같은 명령을 다시 실행하면 멈춘 곳부터 이어서 진행합니다.

브라우저: 일반 다운로드 폴더에 저장하는 모든 브라우저(Chrome, Brave, Edge, Opera, Vivaldi의 다운로드 중 파일 `.crdownload`, Firefox의 `.part`, Safari의 `.download`), 또는 `--downloads`로 지정한 폴더에 저장하는 브라우저. 시스템 폴더는 Linux에서는 `xdg-user-dir`, Windows에서는 레지스트리로 찾습니다(OneDrive 등으로 옮겨졌더라도 찾습니다). Linux에서 테스트했습니다. macOS와 Windows에서도 동작할 것이지만 아직 시험해 보지 않았습니다.

링크는 내보내기를 만든 지 24시간 뒤에 만료됩니다. 그 뒤에는 프로그램이 그 사실을 알리고 새 내보내기를 요청하는 방법을 안내합니다. `https://claude.ai/`로 가는 링크만 열며, 로그인 정보는 전혀 다루지 않습니다. 다운로드는 사용자 자신의 브라우저에서 이루어집니다.

ZIP 파일(또는 압축을 푼 폴더)을 직접 지정할 수도 있습니다:

```
python3 claude-export-viewer.py ~/다운로드/conversations-000.zip -o ~/claude_site
```

주고받은 텍스트가 전혀 없는 대화는 사이트에서 빠집니다. 내보내기에서 삭제된 대화가 이런 모습으로 나타나며, 텍스트로 치지 않는 잔여물(이미지나 첨부 파일, 빈 답변)이 붙어 있기도 합니다. 그래도 포함하려면 `--keep-empty`를 추가하세요.

## 분류

각 대화에는 원하는 분류(“수학”, “의학”, “과학” 등)를 하나씩 붙일 수 있습니다.

- **고르기**: 아이콘으로 목차를 열었을 때, 각 대화 오른쪽의 작은 메뉴에 기존 분류, “분류 없음”, 새로 만들기 위한 **새 분류…**가 나옵니다(최대 40자. “Math”와 “math”는 같은 분류입니다).
- **필터링**: 분류가 하나라도 생기면 다른 필터 옆에 “모든 분류” 메뉴가 나타나며, “분류 없음”과 각 분류를 고를 수 있습니다. 검색, 다른 필터, 모든 정렬과 함께 쓸 수 있습니다. “모든 분류”에서는 모든 대화가 계속 보입니다.
- **관리**: 가져오기 버튼 옆의 **분류 관리** 버튼은 각 분류와 그 대화 수를 보여 주며, 이름을 바꾸거나(기존 분류와 같은 이름으로 바꾸면 두 분류가 합쳐집니다) 삭제할 수 있습니다(대화는 분류 없이 남습니다).

분류는 아카이브(`archive/topics.json`)에 저장됩니다. 사이트를 따라 함께 이동하며(USB 메모리, 다른 브라우저), 이후 가져오기에서도 유지됩니다. 프로그램 없이 `index.html`로 직접 열면 목차는 분류를 보여 주고 필터링도 할 수 있지만, 분류를 바꿀 수는 없습니다.

## 프로그램과 사이트를 둘 곳

프로그램 폴더(`claude-export-viewer`)와 사이트 폴더(`-o`로 고르는 `claude_site`)는 USB 메모리를 포함해 어디에 두어도 됩니다:

```
python3 /media/me/USB/claude-export-viewer/claude-export-viewer.py ~/다운로드 -o /media/me/USB/claude_site
```

그다음 사이트는 `index.html`로, 프로그램이 없어도 어떤 컴퓨터에서나 열립니다(가져오기 버튼과 .odt/.docx 내보내기에는 프로그램이 필요하며, .md와 .pdf 내보내기는 어디서나 됩니다). 아이콘과 페이지에 표시되는 명령은 전체 경로를 기억합니다. USB 메모리가 다른 위치에 마운트되면(다른 컴퓨터, Windows의 다른 드라이브 문자) 새 위치에서 아이콘을 다시 만드세요. 페이지는 다음 가져오기 때 갱신됩니다.

## 언어

이 프로그램은 12개 언어를 지원합니다: 영어, 프랑스어, 스페인어, 독일어, 이탈리아어, 포르투갈어, 네덜란드어, 폴란드어, 러시아어, 중국어(간체), 일본어, 한국어.

- **페이지**는 브라우저의 언어로 열리며, 그 언어가 없으면 영어로 열립니다. 목차 오른쪽 위의 메뉴로 사이트 전체의 언어를 클릭 한 번에 바꿀 수 있습니다: 목차, 대화, 날짜(나라별 형식), 내보내기, 가져오기 로그. 브라우저가 선택을 기억합니다.
- **콘솔 메시지**는 시스템 언어나 `--lang`(`--langue`) 옵션으로 지정한 언어를 따릅니다: `--lang ko`, `--lang de` 등.
- **아이콘 이름**은 세션 언어를 따릅니다(한국어로는 “Claude 보관함”, 영어로는 “Claude Archives” 등).
- 대화 자체는 절대 번역되지 않습니다. 코드와 수식에는 브라우저의 자동 번역이 손대지 않도록 표시가 되어 있습니다.

프랑스어와 영어 외의 번역은 기계 번역입니다. 수정을 환영합니다. 각 언어는 단순한 텍스트 파일 `src/claude_export_viewer/i18n/<코드>.json`입니다. 어떤 언어에 빠진 문장은 영어로 표시됩니다.

## 대화 내보내기(.md, .odt, .docx, .pdf)

각 대화 페이지에는 “내보내기: .md .odt .docx .pdf”와 함께 **다른 버전과 삭제된 부분 포함** 확인란이 있습니다:

- 선택(기본값): 모든 것을 내보내며, 다른 버전과 삭제된 부분은 갈라진 위치의 들여쓴 상자에 들어갑니다;
- 해제: 페이지에 표시된 **기본 흐름**만 내보내며, 파일 이름이 “(기본 흐름)”으로 끝납니다.

브라우저가 마지막 선택을 기억합니다. 명령줄에서는 확인란 해제가 `--main-thread` 옵션에 해당합니다.

- **.md**는 언제나 브라우저에서 바로 됩니다.
- **.pdf**도 언제나 됩니다. 브라우저의 인쇄 창이 열리면 “PDF로 저장”을 고르기만 하면 됩니다. 수식은 화면과 똑같이 보이고, 어두운 모드에서도 흰 배경입니다. 내용은 다른 형식과 같고(생각 과정과 도구 제외) 파일 이름도 제안됩니다.
- **.odt**(LibreOffice)와 **.docx**(Word)는 Pandoc을 거쳐 만들어지며, LaTeX 수식이 실제로 편집 가능한 수식으로 바뀝니다. 한 번 설치하세요(“선택적 의존성” 참고). 쓰는 방법은 두 가지입니다:
  - **클릭 한 번으로**: 내장된 작은 로컬 서버로 사이트를 봅니다:  
    `python3 claude-export-viewer.py -o ~/claude_site --serve`  
    그러면 http://127.0.0.1:8000이 열립니다(멈추려면 Ctrl + C). 이 서버는 내 컴퓨터에서만 접속할 수 있습니다;
  - **명령으로**: 서버 없이 페이지를 연 경우, 버튼이 복사할 명령을 그대로 보여 줍니다. 예를 들어  
    `python3 claude-export-viewer.py -o ~/claude_site --odt "피타고라스"`  
    (제목, 제목의 앞부분 또는 식별자. `--export-dir`로 파일을 쓸 위치를 고릅니다).

Pandoc이 변환하지 못하는 수식은 문서에 LaTeX로 남고, 프로그램이 이를 알려 줍니다.

## 누적 아카이브: 다음 내보내기 추가하기

claude.ai의 각 내보내기는 특정 시점의 계정 스냅숏입니다. 사이트 폴더에는 가져온 모든 내보내기를 쌓아 두는 **아카이브**(`archive/`)가 있습니다. 새 내보내기는 같은 `-o` 폴더로 같은 명령을 실행하기만 하면 됩니다. 새로 생기거나 바뀐 대화만 처리됩니다.

- **중복 없음**: 각 대화는 식별자로 알아봅니다.
- **잃어버리는 것 없음**: claude.ai에서 삭제된 대화도 아카이브에 남으며, 목차에 “claude.ai에서 삭제됨” 표시, 그 페이지에 배너가 붙고, 보이거나 숨기는 필터도 있습니다.
- **사라진 메시지**: 내보내기에는 대화의 모든 버전(수정된 메시지, 다시 생성된 답변)이 들어 있습니다. 그래도 나중의 내보내기에서 메시지가 사라지면 아카이브가 이를 보관하고, 원래 위치의 “claude.ai에서 삭제된 부분” 상자에 보여 줍니다.
- **순서 상관없음**: 최신 내보내기 뒤에 오래된 내보내기를 가져와도 아무것도 덮어쓰지 않고 아카이브를 보충합니다.
- **각 내보내기의 날짜**: 프로그램은 zip 옆에 있는 매니페스트를 찾습니다(여러 개면 내보내기의 가장 최근 메시지 이후에 만들어진 첫 번째 것을 씁니다). 없으면 그 메시지의 날짜를 씁니다. `--export-date YYYY-MM-DD`로 지정할 수도 있습니다.

**사이트 폴더를 지우지 마세요**: `archive/`에는 claude.ai에 더 이상 없는 것을 포함해 대화의 사본이 들어 있습니다. 백업하려면 이 폴더를 복사하세요. 프로그램을 업데이트하려면 프로그램 폴더를 교체한 다음, 내보내기 없이 명령을 실행해 페이지를 다시 만듭니다:

```
python3 claude-export-viewer.py -o ~/claude_site
```

유용한 옵션: `--rebuild`(모든 페이지 다시 만들기), `--structure 내보내기.zip`(내보내기의 필드 이름만 보여 주고 내용은 전혀 보여 주지 않음. 문제를 알릴 때 유용).

진행 상황은 대화 50개마다 표시됩니다. 읽을 수 없는 항목은 건너뛰고, 처리를 멈추지 않은 채 마지막에 경고로 알립니다.

## 원본과 달라진 점

- **일정한 메모리 사용량**: 내보내기 전체를 불러오는 대신 대화를 하나씩 읽고 씁니다(스트리밍). 595 MB짜리 가상 내보내기로 측정: 메모리 최대 57 MB(원본은 파일 크기의 약 4배가 필요).
- **새 내보내기 형식**: 여러 ZIP으로 나뉜 내보내기, 폴더, `.json` / `.jsonl` 파일을 정확한 이름과 상관없이 받아들입니다. 원본은 `conversations.json`만 찾았고, 없으면 오류 없이 “대화 0개”라고 표시했습니다.
- **관용성**: 알 수 없는 콘텐츠 종류(이미지, 웹 검색 등), 예상치 못한 발신자, 빈 칸, 읽을 수 없는 날짜가 있어도 전체 처리가 더 이상 멈추지 않습니다. 일반적인 방식으로 표시하거나 무시합니다.
- **보안**: `javascript:` 링크(및 그 밖의 위험한 프로토콜)는 무력화됩니다. 대화에서 언급된 이미지는 불러오지 않고 링크로 표시됩니다(아카이브는 오프라인에서도 읽을 수 있고 제3자 사이트에 접속하지 않습니다). .odt / .docx 내보내기가 컴퓨터의 파일을 끼워 넣을 수는 없습니다.
- **견고성**: 표시할 수 없는 대화는 알린 뒤 건너뛰며 사이트 생성은 멈추지 않습니다. 손상된 아카이브는 분명한 메시지를 냅니다. 여러 줄에 걸쳐 저장된 프로젝트도 인식합니다.
- **코드 강조 표시**.
- **LaTeX 수식**: Markdown으로부터 보호되며(수식의 `_`, `*`, `\\`가 더 이상 망가지지 않습니다), 생성된 폴더에 포함된 KaTeX 0.16.47로 표시됩니다(연결 불필요). 스크롤에 따라 점진적으로 표시: 수식이 3,000개인 페이지도 1초 안에 열립니다. 인쇄나 PDF 내보내기 전에는 모두 표시합니다.
- 각 코드 상자(코드 블록과 아티팩트)에 claude.ai처럼 언어 이름과 함께 **“복사” 버튼**. 알 수 없는 언어에서 `<code>`가 이중으로 들어가던 문제도 함께 고쳤습니다.
- 여러 번의 내보내기를 모은 **누적 아카이브**: 중복 없음, claude.ai에서 삭제된 대화를 보관하고 표시, 대화에서 삭제된 부분을 원래 위치에 보관, 바뀐 페이지만 다시 만듦.
- 매니페스트를 바탕으로 한 **안내형 다운로드**: 브라우저에서 링크를 하나씩 열고, 각 다운로드가 끝나기를 기다리고, 파일을 아카이브에 정리하고, 가져온 뒤 목차를 엽니다.
- 각 대화의 **Markdown 내보내기**를 클릭 한 번으로. 미리 만들어 둔 파일이 필요 없습니다(내용은 페이지에 들어 있고 파일은 브라우저가 만듭니다).
- Pandoc을 통한 **.odt / .docx 내보내기**(명령 `--odt` / `--docx`, 또는 로컬 서버 `--serve`로 클릭 한 번). Pandoc이 거부하는 LaTeX 구조(`\text{…}` 안의 `\textbf`)를 자동으로 고칩니다.
- **다국어**: 페이지, 콘솔, 내보내기, 아이콘이 12개 언어를 지원하며, 목차에 언어 메뉴가 있습니다.
- **실행 아이콘**(`--install-icon`), 저절로 멈추는 로컬 서버(`--open`), 토큰으로 보호되는 “새 매니페스트 가져오기” 버튼. 전부 또는 기본 흐름만 내보낼 수 있는 “다른 버전 포함” 확인란.
- **uv 의존성 제거**: 시스템의 `python3`용 실행 스크립트 `claude-export-viewer.py`.
- 필터와 관리(이름 바꾸기, 합치기, 삭제)가 가능한 나만의 **분류**. 아카이브에 저장됩니다.
- 설정할 수 있는 **다운로드 폴더**(목차 또는 `--downloads`). 다른 곳에 저장하는 브라우저나 USB 메모리를 위해.
- **Windows**(테스트하지 않음): 다운로드 폴더를 레지스트리에서 읽기, 텍스트는 UTF-8, `py` 명령은 Windows의 따옴표 규칙, 시작 메뉴와 바탕 화면에 바로 가기.
