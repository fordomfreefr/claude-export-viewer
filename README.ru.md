# Claude Export Viewer (версия 2026.10.25.1)

[English](README.md) | [Français](README.fr.md) | [Español](README.es.md) | [Deutsch](README.de.md) | [Italiano](README.it.md) | [Português](README.pt.md) | [Nederlands](README.nl.md) | [Polski](README.pl.md) | **Русский** | [中文](README.zh.md) | [日本語](README.ja.md) | [한국어](README.ko.md)

Превратите историю разговоров Claude.ai в локальный HTML-сайт, который откроется в любом браузере без подключения к Интернету, и ведите накопительный архив своих разговоров, включая те, что с тех пор были удалены на Claude.ai.

Этот проект основан на [claude-export-viewer](https://github.com/lordjabez/claude-export-viewer) Джадсона Нира (Judson Neer), значительно переработанном и дополненном (см. «Лицензия и благодарности»).

> Этот проект независим и не связан с Anthropic. Claude — товарный знак Anthropic.

> Он разработан и протестирован в Linux Ubuntu 26.04, на Python 3.14 и JavaScript. Он должен работать и в Windows. Код написан с помощью Claude (модель Opus 5.5, высокий уровень рассуждений). Этот README — машинный перевод французской версии.

## Быстрый старт в Linux Ubuntu / Debian

1. Получите историю разговоров на claude.ai (интерфейс на английском): **Settings > Privacy > Export data** (Настройки > Конфиденциальность > Экспорт данных). Сначала придёт информационное письмо, а затем второе — со ссылкой для скачивания файла «манифест».

2. Установите 4 библиотеки и Pandoc в терминале:  
`sudo apt install python3-jinja2 python3-mistune python3-pydantic python3-pygments pandoc`

3. Сохраните программу `claude-export-viewer.zip` в `~/Загрузки`.

4. Распакуйте её в свою домашнюю папку и запустите: файлы экспорта будут скачаны по манифесту и импортированы, затем откроется оглавление.  
`cd ~/Загрузки && unzip -o claude-export-viewer.zip`  
`rm -rf ~/claude-export-viewer && mv claude-export-viewer ~/`  
`cd ~/claude-export-viewer`  
`python3 claude-export-viewer.py ~/Загрузки -o ~/claude_site`  
(`rm -rf` удаляет только предыдущую версию программы: ваши разговоры находятся в `~/claude_site`.)

5. Один раз создайте значок запуска на рабочем столе:  
`python3 claude-export-viewer.py -o ~/claude_site --install-icon`

## Возможности

- **Общее оглавление** всех разговоров:
  - поиск по названиям, со счётчиком результатов;
  - сортировка разговоров: по дате создания, дате последнего обмена, названию, числу сообщений;
  - собственные **рубрики**, выбираемые в небольшом меню справа от каждого разговора, для произвольной фильтрации.
- **В каждом разговоре**:
  - местные дата и время, ссылка **Открыть на claude.ai** (если разговор там ещё существует);
  - форматированный Markdown (полужирный шрифт, списки, таблицы) и подсвеченный код (Pygments);
  - рамки кода с названием языка и кнопкой **Копировать** (копирует точный код в буфер обмена);
  - **математические формулы, отображаемые как в LaTeX** (KaTeX, в комплекте, без сети): `$…$`, `$$…$$`, `\(…\)`, `\[…\]`; при копировании фрагмента копируется исходный LaTeX его формул; формула, которую не удаётся отобразить, остаётся в виде исходного текста, с причиной во всплывающей подсказке;
  - отображаемые артефакты (код, документы, HTML/SVG показываются как код и никогда не выполняются);
  - размышления, вызовы инструментов и результаты в сворачиваемых блоках;
  - **несколько версий**: если сообщение было изменено или ответ создан заново, страница следует версии, ведущей к последнему обмену; другие версии находятся в сворачиваемых рамках «Другая версия», в том месте, где разговор разветвился;
  - **экспорт в Markdown, LibreOffice (.odt) и Word (.docx) по запросу**: кнопка «.md» в каждом разговоре; файл содержит основную ветку и, в рамках (цитатах) с подписями курсивом, все другие версии в точке их ветвления (или, при снятом флажке, только основную ветку); формулы в виде `$…$`, код, артефакты и названия вложений включены (без размышлений и результатов инструментов); читается в Typora, Obsidian, Zettlr, преобразуется с помощью Pandoc;
  - **экспорт в PDF** через окно печати браузера, вместе с формулами.
- **Накопительный архив**: последовательные экспорты добавляются без дубликатов, а разговоры, удалённые с тех пор на claude.ai, сохраняются.
- **12 языков** (страницы, консоль, экспорт), выбор в оглавлении.
- **Значок на рабочем столе** (Linux, Windows), который открывает оглавление и одним щелчком импортирует новый экспорт.
- Светлая или тёмная тема, в соответствии с настройкой системы.

## Установка

Распакуйте эту папку куда угодно (диск, USB-накопитель…), затем установите четыре необходимые библиотеки.

**Ubuntu / Debian**: см. «Быстрый старт» выше.

**Windows** (Python 3.11 или новее, с [python.org](https://www.python.org/downloads/) или из Microsoft Store), в терминале (PowerShell или командная строка):

```
py -m pip install jinja2 mistune pydantic pygments
```

В Windows замените в командах этого документа `python3` на `py`, а пути `~/…` — на пути Windows (`C:\Users\[Пользователь]\claude_site`, `E:\claude_site` для USB-накопителя…). **Поддержка Windows написана по документации Python и Windows, но ещё не проверялась на компьютере с Windows**: отзывы приветствуются.

## Значок «Архив Claude» (самый простой способ)

После первого импорта (см. ниже) один раз создайте значок:

```
python3 claude-export-viewer.py -o ~/claude_site --install-icon
```

Он появляется в меню приложений и на рабочем столе (Linux; KDE может один раз попросить доверять ярлыку) или в меню «Пуск» и на рабочем столе (Windows: ярлыки, созданные PowerShell, запускают `pythonw.exe`, поэтому окно консоли не открывается; не проверено). Щелчок открывает оглавление в браузере; его отдаёт небольшой локальный сервер (http://127.0.0.1:8000), который сам останавливается через 30 минут после закрытия последней страницы (`--idle`, чтобы изменить этот срок). Второй щелчок использует уже запущенный сервер, если только его не запустила предыдущая версия программы: тогда он останавливается и заменяется, чтобы действительно использовалась новая версия. Перед созданием значка поместите программу в постоянную папку (например, `~/claude-export-viewer`).

Открытое через значок оглавление собирает настройки в рамке вверху: кнопки **Импортировать новый манифест** и **Управление рубриками**, а под ними папку загрузок с кнопкой **Изменить**. Каждая кнопка открывает свою панель; второй щелчок (или крестик) закрывает её. Кнопка **Импортировать новый манифест**: после того как вы запросили экспорт на claude.ai и перешли по ссылке из письма о том, что данные готовы, она берёт самый свежий манифест из вашей папки загрузок, открывает ссылки по одной (они также отображаются, с возможностью щелчка, в журнале страницы), импортирует экспорт и перезагружает оглавление. Закрытие журнала во время импорта не прерывает его: следующий щелчок снова его показывает.

В той же рамке строка **Папка загрузок** показывает, где ищется манифест. Если ваш браузер сохраняет файлы в другое место (его настройка «Сохранять файлы в» или «Расположение»), нажмите **Изменить** и укажите эту папку: она запоминается в архиве и просматривается первой, раньше системной папки. Пустое поле возвращает системную папку; если выбранная папка исчезнет (USB-накопитель извлечён), используется системная папка.

А в каждом разговоре экспорт в .md, .odt и .docx работает одним щелчком.

**Безопасность**: сервер принимает соединения только с вашего компьютера (127.0.0.1) и не отдаёт исходный архив. Для импорта нужен «секретный токен», который могут прочитать только страницы оглавления, а запросы с другого сайта отклоняются: веб-страница, открытая в том же браузере, не может их вызвать.

## Командная строка

1. На claude.ai: **Settings > Privacy > Export data** (Настройки > Конфиденциальность > Экспорт данных).
2. Когда придёт письмо, перейдите по ссылке из него: браузер скачает небольшой файл «манифест» (список файлов экспорта и их ссылок).
3. Запустите:

```
python3 claude-export-viewer.py ~/Загрузки -o ~/claude_site
```

Программа берёт самый свежий манифест в папке, затем:

- сама открывает каждую ссылку в вашем браузере (где выполнен вход на claude.ai), **по одной**, дожидаясь окончания каждой загрузки (ссылка может перестать работать после использования);
- находит уже скачанные файлы, даже переименованные браузером (`conversations-000 (1).zip`), и пропускает файлы предыдущего экспорта;
- перемещает файлы в `~/claude_site/archive/exports/<дата>/`;
- импортирует экспорт в архив и открывает оглавление.

По умолчанию скачиваются только нужные файлы (разговоры, проекты, учётная запись). Параметры:

- `--all`: скачать все 7 файлов экспорта (полная резервная копия);
- `--browser brave-browser`: выбрать браузер, который открывает ссылки;
- `--manual`: ничего не открывать; ссылки показываются по одной в терминале (Ctrl + щелчок, чтобы открыть, или правый щелчок > копировать адрес, чтобы вставить его в любой браузер), и программа переходит к следующей, как только файл получен;
- `--timeout 600`: ждать каждую загрузку до 600 с (по умолчанию 300, в ручном режиме 900);
- `--no-browser`: не открывать оглавление в конце;
- `--downloads ПАПКА`: запомнить папку, куда браузер сохраняет загрузки (та же настройка, что «Изменить» в оглавлении); `--downloads ""` возвращает системную папку. Сам по себе, без файла для импорта, этот параметр сохраняет настройку и завершает работу.

У каждого параметра есть и французское имя (`--tout`, `--navigateur`, `--manuel`, `--delai`, `--sans-navigateur`, `--telechargements`…), которое показывает `--help`.

**Условие**: в браузере, который открывает ссылки, должен быть выполнен вход на claude.ai (ссылки экспорта работают только в сеансе с выполненным входом). В автоматическом режиме каждая ссылка также показывается в терминале: если открылся не тот браузер, откройте её в нужном, программа всё равно обнаружит файл. Ctrl + C корректно прерывает работу; повторный запуск той же команды продолжает с места остановки.

Браузеры: все, которые сохраняют файлы в обычную папку загрузок (незавершённые загрузки `.crdownload` у Chrome, Brave, Edge, Opera, Vivaldi, `.part` у Firefox, `.download` у Safari), или в папку, указанную через `--downloads`. Системная папка находится с помощью `xdg-user-dir` в Linux и в реестре в Windows (даже если её переместили, например в OneDrive). Проверено в Linux; macOS и Windows должны работать, но ещё не проверялись.

Ссылки действуют 24 часа после создания экспорта; после этого программа сообщает об этом и напоминает, как запросить новый экспорт. Открываются только ссылки на `https://claude.ai/`, никакие учётные данные не обрабатываются: загрузка происходит в вашем собственном браузере.

Можно также указать ZIP-файлы (или распакованную папку) напрямую:

```
python3 claude-export-viewer.py ~/Загрузки/conversations-000.zip -o ~/claude_site
```

Разговоры без единого текстового сообщения на сайт не попадают: так в экспорте выглядят удалённые разговоры, иногда с остатком (изображение или вложенный файл, пустой ответ), который не считается текстом. Добавьте `--keep-empty`, чтобы всё же включить их.

## Рубрики

Каждому разговору можно присвоить рубрику на ваш выбор («математика», «медицина», «наука»…), одну на разговор.

- **Выбор**: когда оглавление открыто через значок, небольшое меню справа от каждого разговора предлагает существующие рубрики, «Без рубрики» и **Новая рубрика…**, чтобы создать новую (не более 40 символов; «Мат» и «мат» — одна и та же рубрика).
- **Фильтрация**: как только появляется хотя бы одна рубрика, рядом с другими фильтрами возникает меню «Все рубрики» с пунктом «Без рубрики» и каждой рубрикой. Оно сочетается с поиском, другими фильтрами и любой сортировкой: при «Все рубрики» все разговоры остаются видимыми.
- **Управление**: кнопка **Управление рубриками** рядом с кнопкой импорта показывает каждую рубрику с числом её разговоров, чтобы переименовать её (переименование в существующую рубрику объединяет обе) или удалить (её разговоры остаются, без рубрики).

Рубрики хранятся в архиве (`archive/topics.json`): они следуют за сайтом (USB-накопитель, другой браузер) и сохраняются при последующих импортах. При открытии напрямую через `index.html`, без программы, оглавление показывает рубрики и позволяет фильтровать по ним, но не изменять их.

## Где разместить программу и сайт

Папка программы (`claude-export-viewer`) и папка сайта (`claude_site`, выбирается через `-o`) могут находиться где угодно, в том числе на USB-накопителе:

```
python3 /media/ya/USB/claude-export-viewer/claude-export-viewer.py ~/Загрузки -o /media/ya/USB/claude_site
```

Затем сайт открывается через `index.html` на любом компьютере, даже без программы (кнопке импорта и экспорту в .odt/.docx нужна программа; экспорт в .md и .pdf работает везде). Значок и команды, показанные на страницах, запоминают полные пути: если накопитель подключён в другом месте (другой компьютер, другая буква диска в Windows), создайте значок заново из нового расположения; страницы обновятся при следующем импорте.

## Языки

Программа говорит на 12 языках: английском, французском, испанском, немецком, итальянском, португальском, нидерландском, польском, русском, китайском (упрощённом), японском и корейском.

- **Страницы** открываются на языке браузера или на английском, если этот язык недоступен. Меню в правом верхнем углу оглавления одним щелчком меняет язык всего сайта: оглавления, разговоров, дат (в формате каждой страны), экспорта и журнала импорта. Браузер запоминает выбор.
- **Сообщения консоли** выводятся на языке системы или на языке, заданном параметром `--lang` (`--langue`): `--lang ru`, `--lang de`…
- **Название значка** соответствует языку сеанса («Архив Claude» по-русски, «Claude Archives» по-английски…).
- Сами разговоры никогда не переводятся. Код и формулы помечены так, чтобы автоматический перевод браузера их не искажал.

Переводы, кроме французского и английского, — машинные: исправления приветствуются. Каждый язык — это простой текстовый файл, `src/claude_export_viewer/i18n/<код>.json`; фраза, отсутствующая в каком-либо языке, показывается по-английски.

## Экспорт разговора (.md, .odt, .docx, .pdf)

Каждая страница разговора предлагает «Экспорт: .md .odt .docx .pdf» и рядом флажок **Включать другие версии и удалённые части**:

- установлен (по умолчанию): экспортируется всё, другие версии и удалённые части — в рамках с отступом, в точке их ветвления;
- снят: экспортируется только **основная ветка** (та, что показана на странице), а имя файла заканчивается на «(основная ветка)».

Браузер запоминает последний выбор. В командной строке снятому флажку соответствует параметр `--main-thread`.

- **.md** работает всегда, прямо в браузере.
- **.pdf** тоже работает всегда: открывается окно печати браузера, где достаточно выбрать «Сохранить как PDF». Формулы выглядят точно так же, как на экране, на белом фоне даже в тёмном режиме; содержимое такое же, как в других форматах (без размышлений и инструментов), а имя файла предлагается автоматически.
- **.odt** (LibreOffice) и **.docx** (Word) создаются через Pandoc, который превращает формулы LaTeX в настоящие редактируемые формулы. Установите его один раз (см. «Необязательные зависимости»). Два способа:
  - **одним щелчком**, просматривая сайт через небольшой встроенный локальный сервер:  
    `python3 claude-export-viewer.py -o ~/claude_site --serve`  
    затем открывается http://127.0.0.1:8000 (Ctrl + C, чтобы остановить). Сервер доступен только с вашего компьютера;
  - **командой**, если страница открыта без сервера: кнопка показывает точную команду для копирования, например  
    `python3 claude-export-viewer.py -o ~/claude_site --odt "Пифагор"`  
    (название, начало названия или идентификатор; `--export-dir`, чтобы выбрать, куда записать файл).

Формулы, которые Pandoc не может преобразовать, остаются в документе в виде LaTeX, и программа сообщает о них.

## Накопительный архив: добавление следующих экспортов

Каждый экспорт claude.ai — это снимок вашей учётной записи в определённый момент. Папка сайта содержит **архив** (`archive/`), который накапливает все импортированные экспорты. Для нового экспорта просто запустите ту же команду с той же папкой `-o`: обрабатываются только новые или изменённые разговоры.

- **Без дубликатов**: каждый разговор распознаётся по его идентификатору.
- **Ничего не теряется**: разговор, удалённый на claude.ai, остаётся в архиве, с отметкой «Удалена на claude.ai» в оглавлении, баннером на его странице и фильтром, чтобы показать или скрыть такие разговоры.
- **Исчезнувшие сообщения**: экспорт содержит все версии разговора (изменённые сообщения, повторно созданные ответы). Если сообщения всё же исчезнут из последующего экспорта, архив сохранит их и покажет на своих местах, в рамке «Часть, удалённая на claude.ai».
- **Любой порядок**: импорт более старого экспорта после более нового дополняет архив, ничего не перезаписывая.
- **Дата каждого экспорта**: программа ищет манифест рядом с zip-файлом (если их несколько, берёт первый, созданный после самого свежего сообщения экспорта); иначе берёт дату этого сообщения. Её также можно указать параметром `--export-date ГГГГ-ММ-ДД`.

**Не удаляйте папку сайта**: `archive/` содержит копию ваших разговоров, включая те, которых больше нет на claude.ai. Для резервного копирования скопируйте эту папку. Чтобы обновить программу, замените папку программы, затем запустите команду без экспорта, чтобы пересоздать страницы:

```
python3 claude-export-viewer.py -o ~/claude_site
```

Полезные параметры: `--rebuild` (пересоздать все страницы), `--structure ЭКСПОРТ.zip` (показывает только имена полей экспорта, без какого-либо содержимого: полезно, чтобы сообщить о проблеме).

Ход работы показывается каждые 50 разговоров. Нечитаемые элементы пропускаются, и в конце выводится предупреждение, без остановки обработки.

## Изменения по сравнению с оригиналом

- **Постоянный расход памяти**: разговоры читаются и записываются по одному (потоково), вместо загрузки всего экспорта. Измерено на искусственном экспорте размером 595 МБ: не более 57 МБ памяти (оригиналу нужно около 4 размеров файла).
- **Новый формат экспорта**: принимается экспорт, разбитый на несколько ZIP-файлов, папка или файлы `.json` / `.jsonl`, независимо от их точного имени. Оригинал искал только `conversations.json`, а иначе без ошибки сообщал «0 разговоров».
- **Устойчивость к данным**: неизвестный тип содержимого (изображение, веб-поиск…), неожиданный отправитель, пустое поле или нечитаемая дата больше не останавливают всю обработку; они показываются в общем виде или пропускаются.
- **Безопасность**: ссылки `javascript:` (и другие опасные протоколы) обезвреживаются; изображения, упомянутые в разговоре, показываются как ссылки, без загрузки (архив остаётся читаемым без сети, без обращения к сторонним сайтам); экспорт .odt / .docx не может встроить файл с компьютера.
- **Надёжность**: разговор, который невозможно отобразить, отмечается и пропускается без остановки создания сайта; повреждённый архив даёт понятное сообщение; проект, сохранённый в нескольких строках, распознаётся.
- **Подсветка кода**.
- **Формулы LaTeX**: защищены от Markdown (символы `_`, `*` и `\\` в формулах больше не портятся), затем отображаются KaTeX 0.16.47, который входит в создаваемую папку (подключение не нужно). Постепенное отображение при прокрутке: страница с 3000 формул открывается менее чем за секунду; перед печатью или экспортом в PDF отображается всё.
- **Кнопка «Копировать»** у каждой рамки кода (блоки кода и артефакты), с названием языка, как на claude.ai; заодно исправлен двойной `<code>` для неизвестных языков.
- **Накопительный архив** последовательных экспортов: без дубликатов, разговоры, удалённые на claude.ai, сохраняются и отмечаются, удалённые части разговора сохраняются на своих местах, пересоздаются только изменённые страницы.
- **Управляемая загрузка** по манифесту: ссылки открываются по одной в браузере, ожидание окончания каждой загрузки, файлы складываются в архив, импорт и открытие оглавления.
- **Экспорт в Markdown** каждого разговора одним щелчком, без заранее созданного файла (содержимое встроено в страницу, а файл создаёт браузер).
- **Экспорт .odt / .docx** через Pandoc (команда `--odt` / `--docx` или одним щелчком через локальный сервер `--serve`); автоматическое исправление конструкции LaTeX, которую Pandoc отвергает (`\textbf` внутри `\text{…}`).
- **Многоязычность**: 12 языков для страниц, консоли, экспорта и значка, с меню выбора языка в оглавлении.
- **Значок запуска** (`--install-icon`), локальный сервер, который сам останавливается (`--open`), кнопка «Импортировать новый манифест», защищённая токеном; флажок «Включать другие версии», чтобы экспортировать всё или только основную ветку.
- **Больше никакой зависимости от uv**: программа запуска `claude-export-viewer.py` для системного `python3`.
- **Собственные рубрики** с фильтром и управлением (переименование, объединение, удаление), хранящиеся в архиве.
- **Настраиваемая папка загрузок** (оглавление или `--downloads`) для браузера, сохраняющего файлы в другое место, или USB-накопителя.
- **Windows** (не проверено): папка загрузок читается из реестра, тексты в UTF-8, команды `py` с кавычками Windows, ярлыки в меню «Пуск» и на рабочем столе.
